**每页固定动作**

1. 从入口进一次，再用路由直达一次，确认不白屏、返回正常。
2. 手机截图（含状态栏），与源图按宽度对齐，叠 50% 看三条锚线：页面标题、第一个卡片顶边、底部按钮/悬浮 tabbar。
3. 记录最大偏差（px）与位置；≤1px 记「过」，1–3px 记「观察」，>3px 记「修」。
4. 状态栏、微信胶囊不参与比对；H5 测试需注明「无状态栏」。
