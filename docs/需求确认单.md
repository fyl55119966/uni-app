## 一、项目概述

- 产品定位：线上黄金现货商城，提供投资金条的在线订购、预约提货，以及旧金回收申请。
- 用户路径：浏览金价与商品 → 下单付定金 → 补尾款 → 到店自提/物流收货；或提交回收申请 → 寄送/到店 → 验收 → 收款。
- 本期边界：只做前端页面、交互与模拟数据；不含后端、真实支付、真实物流、真实行情。
- 设计依据：客户提供的 69 张页面截图及图片素材，品牌与文案沿用截图。

## 三、需求细则（B1–B3 已确认，B4 部分确认，B5–B7 待确认）

### B1 提货与退款细则（已确认 2026-11-19）

| 编号 | 问题 | 我方建议 |
| --- | --- | --- |
| B1.1 | 「30 天内未提货可退定金」是否收手续费？ | 不收，定金原路退回 |
| B1.2 | 已补尾款但未提货，尾款是否全退？ | 未发货：定金 + 尾款全退；已发货未签收：扣实际运费 + 保价，余款全退；已签收：不支持退，走售后 |
| B1.3 | 退款时优惠券、新人补贴是否退回？ | 券退回原券、有效期不变、过期不补；补贴退回账户，仍限抵定金、30 天有效、不重置有效期 |
| B1.4 | 30 天从哪天起算？ | 从支付定金成功之日起算 |
| B1.5 | 逾期后是否设宽限期？ | 不设宽限期；逾期即按 A5 执行 |

### B2 回收规则（已确认 2026-11-19）

| 编号 | 问题 | 我方建议 |
| --- | --- | --- |
| B2.1 | 回收款打到余额还是银行卡？ | 打入账户余额，可再提现 |
| B2.2 | 寄送物流与保价由谁承担？ | 支持寄送与到店：寄送由客户承担运费与保价；到店用运营中心门店，验收后打款 |
| B2.3 | 验收标准是否固定 99.9%？ | 固定 99.9%，以平台检测为准 |
| B2.4 | 违约（成色不足/超期）如何扣保证金？ | 成色不足按实测差额从回收款扣；超期不寄或虚假申报扣全部履约保证金 |
| B2.5 | 打款时效？ | 验收通过后 7 个工作日内 |

### B3 资金与营销（已确认 2026-11-19）

| 编号 | 问题 | 我方建议 |
| --- | --- | --- |
| B3.1 | 余额充值渠道？ | 支付宝 + 大额转账（线下对公）；金额任意输入；单笔 ≤5 万走支付宝（截图 355） |
| B3.2 | 新人补贴 1000 元的规则？ | 仅抵定金、不可提现、有效期 30 天 |
| B3.3 | 优惠券适用范围？ | 先抵定金，超出额度结转尾款；过期作废；退款按 B1.3 退未用部分 |
| B3.4 | 补贴与优惠券能否叠加？ | 可叠加；补贴先抵定金（不结转、不找零），券再抵剩余定金并可结转尾款；合计不超订单总额 |
| B3.5 | 提现规则？ | T+1 到账、无手续费、单笔最低 100 元、到银行卡 |
| B3.6 | 支付密码？ | 6 位数字；支付、提现时校验 |
| B3.7 | 支付方式？ | H5 收银台：支付宝（≤5 万）+ 余额（6 位密码）+ 大额转账（>5 万，对公账户 + 上传凭证，弹层，不新增页）；尾款超 5 万自动切大额转账；小程序端支付/充值全部 mock，页面标注「测试环境」 |
